# Deterministic runtime UI inputs

The guarded marketing-capture test populates the locale/device folders beneath this directory with the exact safe-synthetic-data product states declared by `narrative-alternatives.json` and recorded in `source-captures.json`.

Do not add mockups, third-party screenshots, personal data, production CloudKit data, or manually reconstructed UI. Every PNG must be opaque RGB, match its named simulator's native pixel dimensions, and have its SHA-256 and capture provenance bound in `source-captures.json`.
