# Garden design lab

This local comparison harness renders three original visual compositions over the same validated `GardenState` contract. It does not add persistence, progression, bridge, or network authority.

- **Verdant Atelier** emphasizes botanical specificity, restrained painted facets, and warm daylight.
- **Paper Sanctuary** uses flattened illustrated layers, tactile depth, and quiet cut-edge shadows.
- **Twilight Refuge** uses an indigo/amber silhouette, restrained particles, and calm evening light.

`scripts/generate-garden-design-lab.mjs` blocks external network access and creates matched iPhone/iPad stills, contact sheets, motion clips, objective renderer diagnostics, checksums, and a manifest. The lab route and unselected direction modules are not included in the app renderer bundle. Owner selection and physical performance review remain separate gates.
