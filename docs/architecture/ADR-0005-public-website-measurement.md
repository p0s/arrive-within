# Public website activity estimates

The public website extends its existing permitted document counts with two separate browser signals: ten cumulative visible seconds, and ten visible seconds plus trusted input. A single first-party module sends each once per document. It also counts activation of the existing public source link as an aggregate action. These are traffic and activity estimates; none verifies a person or an app installation.

The Worker allows the module to operate only after the existing public-route, DNT, GPC, opt-out, prefetch and recognizable-bot checks. Available verified-bot metadata is also respected. Every signal repeats those checks. Unknown automation remains possible. Responses carry a noncached permission marker so one visitor's choice cannot enable another visitor's module.

Signals contain no text, query, fragment, cookie identifier or arbitrary properties. Actions and collection-stage receipts contain no visitor fields. Labelled technical QA remains separate from audience and business totals, including after history changes. A bounded server delivery retry uses the collector's frozen event contract; uncertain retries cannot create a second event.

This decision applies only to public website measurement. The native app, journal, account model, reviewed public media and app privacy contract remain unchanged. The website uses no third-party browser analytics or advertising SDK. Operational access and deployment bindings remain private.
